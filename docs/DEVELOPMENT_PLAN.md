# План разработки

1. `docs/specification` — требования, архитектура и тест-план.
2. `feat/android-foundation` — Gradle, Compose, тема, навигация.
3. `feat/game-catalog` — RAWG, каталог, поиск и детали.
4. `feat/library-cache` — Room, DataStore, избранное и офлайн-кэш.
5. `feat/analytics` — исторические запросы, статистика и два графика.
6. `test/release-readiness` — тесты, CI, документация и APK.

Каждый этап проходит через отдельный Pull Request. Слияние выполняется после проверки соответствующего этапа.
