# GameDex — Discover. Track. Play.

GameDex — нативный каталог видеоигр, локальная игровая библиотека и аналитическая платформа для Android 12+. Приложение загружает реальные данные из RAWG, сохраняет просмотренные игры и аналитику в Room и остаётся полезным без сети.

> Перед сдачей студент должен подтвердить преподавателю тему/показатель и то, что в лабораторной №3 не использовался Kotlin.

## Возможности

- премиальный тёмный интерфейс Jetpack Compose с адаптивной нижней навигацией;
- главная страница с hero-блоком, популярными и высокооценёнными играми;
- поиск с debounce, пагинацией, жанром, платформой, годом и сортировкой;
- подробности игры, RAWG-рейтинг, Metacritic, жанры, платформы, разработчики и ссылки;
- избранное и статусы «Хочу пройти», «Прохожу», «Пройдено»;
- локальный поиск и фильтрация библиотеки;
- отдельные экраны аналитики за 7 и 30 завершённых дней;
- интерактивный Canvas-график, min/max/average/delta/percentage/trend;
- Room-кэш, DataStore-настройки, fallback при отсутствии сети и дисковый кэш Coil;
- обработка 401/403, 429, 5xx, timeout, некорректного JSON и неполных данных.

## Стек и архитектура

Kotlin, Jetpack Compose, Material 3, MVVM, Coroutines/Flow, Retrofit/OkHttp, Kotlin Serialization, Room, DataStore, Coil, Navigation Compose и Gradle Kotlin DSL. Код разделён на Compose UI, ViewModel, repository, remote/local data source, DTO/entity и чистую domain-логику.

## RAWG API и ключ

Источник: [RAWG Video Games Database](https://rawg.io/apidocs). Ключ не находится в репозитории и не выводится в лог. При первом запуске без ключа GameDex показывает экран настройки. Получите бесплатный ключ на странице RAWG, вставьте его и нажмите «Проверить и сохранить»; значение хранится локально в DataStore.

Для локальной сборки ключ необязателен. При желании можно создать непубликуемый `~/.gradle/gradle.properties`:

```properties
RAWG_API_KEY=ваш_ключ
```

## Аналитика 7/30 дней

Для каждого из последних 30 завершённых календарных дней выполняется документированный запрос `/games?dates=DATE,DATE&page_size=1`; показателем является поле `count`. Одновременно выполняется не более четырёх запросов. Текущий день исключён. Успешные значения сохраняются в Room, свежий кэш не загружается повторно, а сетевые ошибки не превращаются в нули. Поэтому график можно построить сразу после установки, не ожидая 30 дней.

## Запуск и сборка

1. Откройте корень проекта в Android Studio с JDK 17.
2. Установите Android SDK 35.
3. Дождитесь Gradle Sync и запустите конфигурацию `app` на Android 12+.

Windows:

```powershell
gradlew.bat testDebugUnitTest
gradlew.bat assembleDebug
```

Linux/macOS:

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
```

APK создаётся в `app/build/outputs/apk/debug/app-debug.apk`. CI также публикует его как downloadable artifact.

## Установка на Samsung Galaxy M31s

1. Скачайте APK из [GitHub Releases](https://github.com/Sergo379/psiahramenco3_4/releases).
2. Разрешите установку неизвестных приложений для браузера/файлового менеджера.
3. Откройте APK, подтвердите установку и запустите GameDex.
4. Введите личный RAWG API-ключ на первом экране.

APK имеет `minSdk 31`, рассчитан на Android 12 и подписан стандартным debug-ключом (тестовая установка, не Play Store release).

## Проверка офлайн-режима

При включённом интернете откройте главную, выполните поиск, откройте несколько карточек, добавьте игры в библиотеку и загрузите аналитику. Закройте приложение, включите режим полёта и запустите снова: библиотека, статусы, ранее просмотренные данные и сохранённая аналитика остаются доступны; интерфейс помечает кэш и не удаляет его при ошибке обновления.

## Ограничения

- полнота, изображения и значения `count` зависят от базы RAWG и её тарифа;
- первый сетевой запуск требует персонального ключа;
- процент при переходе от нуля к положительному значению не определён;
- без ранее заполненного кэша сетевые разделы не могут показать данные;
- физическая проверка на Samsung Galaxy M31s должна быть выполнена студентом.
